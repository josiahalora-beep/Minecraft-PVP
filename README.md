# Minecraft-PVP — Daegon Reborn Simulation

Local Minecraft **1.8.8 Factions-era simulation** aimed at recreating old-school raiding/economy/social gameplay with HCF-style PotPvP.

## Locked rules
- No mcMMO.
- Not KitPvP.
- Farming (especially sugar cane) is a first-class economy path.
- Donor ranks use valuable kits on real cooldowns; death still matters.
- Owner is a real in-world player.
- Measure before making scale claims.

Phase 0 builds the PolyMC client instance, local 1.8.8 server baseline, deterministic test map, ranks/kits/economy/faction basics, and the three measurement spikes: duel, idle-client scaling, and reconnect/state persistence.
