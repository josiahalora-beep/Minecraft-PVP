# Daegon Critical Design Doctrines

These documents are mandatory design standards for production work.

## Terrain / Environmental Art
Read before changing terrain, roads, event surroundings, wilderness, faction-site terraforming, or structure-to-landscape integration:
- `docs/TERRAIN_PERSONA_AND_WORKFLOW.md`

## HCF Faction Base Architecture
Read before changing base planning, concealment, exterior generation, semantic anchors, claims, or base terrain integration:
- `docs/HCF_BASE_PERSONA_AND_WORKFLOW.md`

## Enforcement
- Terrain/base changes must be reviewed against the current visual QA screenshots.
- Functional HCF constraints and semantic anchors remain load-bearing.
- A later doctrine may override a rule only when it explicitly names the conflicting rule.
- Do not silently restore deprecated flat-map or generic-box assumptions.
