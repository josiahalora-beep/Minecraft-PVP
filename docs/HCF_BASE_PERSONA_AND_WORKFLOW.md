# Daegon Critical HCF Base Architecture Doctrine

## Status: mandatory

All faction-base planning, generation, concealment, semantic layout and terrain integration must follow this file and the Critical Terrain Doctrine.

## Persona
Principal Base Architect & Terrain-Integration Specialist.

A base that obviously reads as a generated building from 50+ blocks away has failed.

## 0. Reference & Constraint Check
Before a substantial base blueprint:
- inspect the current site screenshot/map;
- identify terrain, biome and local palette;
- preserve fixed entrance, storage/vault, f-home, brewer, dropdown/elevator and portal anchors;
- account for faction tier/wealth/build quality.

## 1. Concealment-First Geometry
- Prefer partial embedding into a ridge/slope/berm over freestanding boxes.
- Exterior terrain/disguise uses irregular tapering curvature.
- Interior functional rooms remain practical and rectilinear.
- Entry approaches must not read as a cleared runway or decorative road.
- Avoid giant exposed glass roofs and repeated rectangular shells.

## 2. Local-Match Texturing
Sample the actual site.
Exterior/terrain blend follows local material language with cohesive ~70/20/10 patches.
No hard built/natural edge and no random block confetti.

## 3. Functional Zone Integration
Semantic anchors are load-bearing and stable:
- primary/secondary entrance
- dropdown
- elevator
- storage/vault
- refill
- f-home
- brewer
- farm
- enchant
- war room
- utility
- Nether/End portal
- traps

Visual concealment may wrap these anchors but may not move/block them.

## 4. Reversed Negative Space
Use terrain, shadow, recesses, vegetation and broken sightlines to reduce distant signature.
Detail should reward close inspection; exterior should read as ordinary terrain first.

## 5. Faction Tier
Scrappy: rougher excavation, modest concealment, practical finish.
Established: clean integration, organized systems, proper transit.
Power faction: sophisticated concealment/earthwork and redundancy, but still normal HCF scale.

## 6. Family Grammar
Redemption, Base-HCF, ModernHCF, Tunnel and Cave must change actual topology, excavation, approach, shell visibility and terrain cradle.
They are not five versions of the same glass/stone box.

## 7. Claims/Roads
Claims stay rectangular and cover all modules plus buffer.
Claim geometry must never become visible terrain geometry.
A base/claim may not intersect the protected canonical road corridor.

## 8. Bot Habitability
Bases must support real player-like loops: storage, refill, brew, farm, regroup, armor/loot banking, KOTH prep.
Entrances, one-block rises, dropdowns and elevators must be physically reliable for Mineflayer.

## 9. Failure Conditions
Reject a base when:
- it is an obvious box;
- multiple factions look cloned;
- terrain is merely flattened around it;
- claim outline dominates the site;
- a straight path announces the door;
- palette ignores local terrain;
- terrain cuts hard against walls;
- entrance/farm/portal modules look pasted on;
- bots cannot traverse it smoothly.

For substantial base work, use:
0. Reference & Constraint Check
1. Concealment-First Geometry
2. Local-Match Texturing
3. Functional Zone Integration
4. Reversed Negative Space
5. Tool / Procedural Workflow
