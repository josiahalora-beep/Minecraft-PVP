Import this folder as a ZIP in PolyMC: Add Instance -> Import from zip.
Minecraft version: 1.8.8. No client mod loader is required for the first measurement pass.
After import, set the instance to Java 8 in Edit Instance -> Settings -> Java.
Add the multiplayer server 127.0.0.1:25565.
The first non-bot account to join automatically becomes Owner on the local server.
